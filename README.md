# Мизанплас — 103 рецепта

Статический сайт, серверная часть не нужна.

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите содержимое этой папки в корень.
2. Settings → Pages → Source: Deploy from a branch → main / (root).
3. Через минуту сайт открыт по адресу https://<логин>.github.io/<репозиторий>/

## Файлы
- index.html — приложение целиком (разметка + логика)
- support.js — среда выполнения, обязателен
- recipes-a.js, recipes-b.js — 103 рецепта, которые читает приложение
- photo-queries.js — поисковые запросы к фотостоку
- photos.js — ссылки на фотографии; сейчас пусто, вместо фото рисуются генеративные обложки
- image-slot.js — перетаскивание своего фото (работает только в редакторе)
- recipes.json — те же рецепты в формате JSON, для переноса в другие проекты
- images.json — резерв под карту изображений

## Как добавить фотографии
1. Откройте сайт с адресом ...?admin
2. Вставьте ключ Pexels (pexels.com/api), нажмите «Загрузить фото».
3. Нажмите «Скопировать список» и вставьте полученный текст в photos.js вместо строки export const PHOTOS = {};
4. Загрузите обновлённый photos.js в репозиторий. Ключ в публичной версии не нужен.

## Важно
Открывать index.html двойным щелчком с диска нельзя — модули не грузятся по протоколу file://. Нужен GitHub Pages или локальный сервер: python3 -m http.server
